# AdministracijaKorisnika - WPF & SQL Aplikacija

Ovaj projekat predstavlja desktop aplikaciju za upravljanje i administraciju korisničkih naloga razvijenu u **WPF (Windows Presentation Foundation)** tehnologiji, povezanu sa **SQL bazom podataka**. 

## Ključne funkcionalnosti
* **CRUD upravljanje korisnicima:** Unos novih korisnika, pregled postojećih podataka, ažuriranje informacija i brisanje naloga.
* **Rad sa relacionim bazama:** Strukturisana SQL skripta (`baza.sql`) za kreiranje tabela, definisanje primarnih ključeva i skladištenje podataka o korisnicima.
* **Grafički interfejs (UI):** Deklarativni dizajn interfejsa kreiran pomoću XAML-a, koji omogućava intuitivan i čist korisnički rad.
* **Razdvajanje logike:** Primena standardnog C# koda u pozadini (Code-behind) za povezivanje vizuelnih komponenti sa podacima iz baze.

## Tehnologije i alati
* **Interfejs:** WPF (XAML)
* **Jezik:** C# (.NET)
* **Baza podataka:** Microsoft SQL Server / T-SQL (`baza.sql`)
